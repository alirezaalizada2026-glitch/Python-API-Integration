API Integration with Python

About the Project

This project demonstrates how to retrieve data from an external API using Python and the Requests library.

The program connects to the JSONPlaceholder API, retrieves posts, displays them in the terminal, and saves the selected data in a JSON file.

Features

- Fetch data from an external API using GET requests.
- Retrieve posts based on user input.
- Display post IDs, titles, and bodies.
- Save retrieved data in a JSON file.
- Validate user input.
- Handle connection, HTTP, and JSON errors.

Technologies Used

- Python 3
- Requests
- JSON
- JSONPlaceholder API

Installation

Install the Requests library:

pip install requests

How to Run

python api_test.py

Enter the number of posts you want to retrieve.

The selected posts will be displayed in the terminal and saved in "posts.json".
